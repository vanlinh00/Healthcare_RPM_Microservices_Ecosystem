          🔧 Microservice Endpoints & Keycloak IdP Architecture
        

        

          

            1Get Auth URL
            

              GET /api/v1/auth/google/url

              Returns Keycloak authorization endpoint with kc_idp_hint=google.
            

          

          

            2Exchange Code
            

              POST /api/v1/auth/google/callback

              Exchanges OAuth code for Keycloak JWT tokens and provisions user.
            

          

          

            3ID Token Login
            

              POST /api/v1/auth/google/token

              RFC 8693 token exchange for Google SDK / One Tap signed tokens.
            

          

          

            4IDP Setup Config
            

              GET /api/v1/auth/google/config

              Keycloak broker redirect URI and Google Cloud Console instructions.
